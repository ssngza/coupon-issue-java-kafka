# Product Spec: 선착순 쿠폰 발급 클라이언트 인터페이스

## 1. 개요

브라우저에서 테스트할 수 있는 경량 정적 SPA 웹 UI 인터페이스 명세입니다.

## 2. 주요 기능 요구사항

- **실시간 재고 조회**: 2초 간격 Polling을 통해 Redis 잔여 수량 실시간 표시
- **단일 발급 요청**: 사용자 ID를 입력하여 `POST /api/coupons/{id}/issue` 호출
- **다중 동시 요청 시뮬레이션**: 10명의 가상 유저 ID를 생성하여 0.1초 내 동시 발급 요청 트리거
- **실시간 로그 창**: API 요청 결과(성공/실패 메시지)를 콘솔 뷰 형태로 실시간 출력
